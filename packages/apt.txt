# apt package list for Linux (Ubuntu) — the counterpart to the brew lines
# in packages/Brewfile.
#
# Line format:
#
#   name [@tag] [# comment]
#
# Blank lines and '#' comments are ignored. The columns below are cosmetic: the
# parser collapses the padding. An optional tag restricts the line to the
# machines it applies to; untagged lines apply everywhere:
#
#   @wsl      only under WSL
#   @!wsl     only outside WSL
#   @ubuntu   only on Ubuntu or a derivative — is_ubuntu greps all of /etc/os-release
#
# @ubuntu is supported but currently unused — every line below is either untagged
# or WSL-tagged.
#
# This list is the only place package names live. setup/packages-linux.sh adds
# the apt sources first (WakeMeOps, the git PPA, NodeSource) and then installs
# everything here in one go. Only what apt cannot provide at all is installed
# separately there: helix (classic snap), antidote (git clone) and starship
# (upstream installer).
#
# Not listed on purpose:
#
#   git-credential-libsecret   not an apt package. setup/git.sh probes for it and
#                              falls back to the 1 h credential cache, so git
#                              works either way.
#   helix                      no apt package under that name, and the PPA it used
#                              to come from stopped at oracular (24.10). Installed
#                              as a classic snap by setup/packages-linux.sh, which
#                              is why `snapd` is listed below.
