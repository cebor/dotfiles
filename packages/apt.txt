# apt package list for Linux (Debian/Ubuntu) — the counterpart to the brew lines
# in packages/Brewfile.
#
# Line format:
#
#   name [@tag] [# comment]
#
# Blank lines and '#' comments are ignored. The columns below are cosmetic: the
# parser collapses the padding. An optional tag restricts the line to the
# machines it applies to; untagged lines apply everywhere:
#
#   @wsl      only under WSL
#   @!wsl     only outside WSL
#   @ubuntu   only on Ubuntu, not on plain Debian
#
# This list is the only place package names live. setup/packages-linux.sh adds
# the apt sources first (WakeMeOps, the git and helix PPAs, NodeSource) and then
# installs everything here in one go. Only what apt cannot provide at all is
# installed separately there: antidote (git clone) and starship (upstream
# installer).
#
# Not listed on purpose:
#
#   git-credential-libsecret   not an apt package on Debian/Ubuntu. setup/git.sh
#                              probes for it and falls back to the 1 h
#                              credential cache, so git works either way.

# ─────────────────────────────────────────────────────────────────────────────

# ─────────────────────────────────────────────────────────────────────────────
zsh
tmux
coreutils
findutils
wget
rsync

procps                      # provides `watch`
locales                     # locale-gen, for the LANG in home/.exports (setup/locale.sh)
